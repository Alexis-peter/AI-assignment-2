# Titanic Survival Prediction - Feature Engineering Project

## 🎯 Project Overview
This project implements a comprehensive feature engineering pipeline for the Titanic survival prediction problem. The goal is to build a robust predictive model by performing systematic data cleaning, feature engineering, and feature selection.

## 📊 Dataset
- **Source**: Kaggle Titanic Competition
- **Training Data**: 891 passengers with survival labels
- **Test Data**: 418 passengers for prediction
- **Target Variable**: Survived (0 = No, 1 = Yes)
